MONEY MANAGER SMART MONEY V5

จุดเด่น
- UI ใหม่ตามคอนเซปต์ที่ออกแบบไว้: Dark Navy + Green/Red/Blue/Purple
- Responsive ใช้ได้ทั้ง PC และมือถือ
- PWA ติดตั้งเป็นแอปได้
- ฐานข้อมูล IndexedDB เก็บรายการในเครื่อง
- สแกนสลิป: อ่าน OCR แล้วบันทึกรายการให้อัตโนมัติ โดยไม่ต้องกดบันทึกซ้ำ
- เพิ่มรายการเองได้
- ประวัติ / ค้นหา / รายงาน / หมวดหมู่
- สำรองและนำเข้าข้อมูล JSON

การใช้บน PC
1) แตก ZIP
2) เปิดด้วย local server เพื่อให้ PWA ทำงานเต็มระบบ เช่นเปิด CMD ในโฟลเดอร์แล้วใช้: py -m http.server 8000
3) เปิด Chrome: http://localhost:8000
4) ถ้าต้องการติดตั้งเป็นแอป ให้ใช้ Chrome เมนูติดตั้ง (PWA)

การใช้บนมือถือ
- ต้องเปิดจาก HTTPS หรือโฮสต์เว็บไซต์ก่อนจึงติดตั้ง PWA ได้
- Android Chrome: เมนู ⋮ > ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก
- iPhone Safari: Share > Add to Home Screen

หมายเหตุ OCR
- การอ่านสลิปใช้ Tesseract.js จาก CDN และต้องมีอินเทอร์เน็ตตอนโหลด OCR หากยังไม่ได้แคช
- ระบบจะบันทึกทันทีหลัง OCR เสร็จตามที่กำหนด หากยอดเงินอ่านผิด ให้แก้รายการจากประวัติในรุ่นถัดไป/พัฒนาต่อได้
